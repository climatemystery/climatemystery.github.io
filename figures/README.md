# Research figures

Place only figures that you have permission to publish on this website in this folder.

## Add a figure

1. Export a web-ready PNG, JPEG, or WebP image. Keep a high-resolution original elsewhere.
2. Add the image file to this folder, for example `mountain-precipitation-change.png`.
3. Add one entry to `manifest.json` using the fields below.
4. Replace the example entry and image path. Do not leave placeholder captions in the public gallery.

## Manifest fields

- `image`: relative path to the image inside this folder.
- `alt`: factual description for accessibility.
- `title`: figure title.
- `topic`: research theme shown as a small label.
- `caption`: short scientific explanation, including units or period where needed.
- `model`: model or analysis method, if relevant.
- `dataset`: dataset or observational source, if relevant.
- `period`: time period covered.
- `publication`: DOI or article URL, if the figure is associated with a paper.

## Suggested first figures

- Mountain precipitation response under CO2 warming.
- Eastern Himalayan monsoon rainfall and circulation.
- Persistent mountain snow-cover changes.
- Norway WRF land-cover experiments: precipitation, evapotranspiration and surface energy balance.

Check publisher permissions before uploading published figures. Do not upload confidential project data or figures belonging to collaborators without permission.
